The oxl: vocabulary

The terms oxilite uses in its system graphs: the schema registry in <oxilite:schema> (which named graphs hold ontologies, SHACL shapes or ShEx schemas, and which graphs each applies to) and the history graph <oxilite:history>. Everything here is plain RDF: any SPARQL 1.1 store can hold, query and update it.

Namespace https://oxilite.dev/ns# · prefix oxl: · Turtle · source vocab/oxl.ttl · reference schema registry · article Graphs that describe graphs

System graphs

GraphHolds
<oxilite:schema>The schema registry: one description per registered graph (subject: the graph's IRI, or oxl:DefaultGraph), plus descriptions of the system graphs
<oxilite:vocabulary>This vocabulary, installed in new stores created by the oxilite command line or with the system_graphs / systemGraphs option
<oxilite:history>The change log of a versioned store, as a virtual graph of commits (prov:Activity) and their oxl:added / oxl:removed triples

Classes

TermLabelMeaning
oxl:SchemaGraphschema graphA named graph holding schema rather than data. Described in <oxilite:schema> with the graph's own IRI as subject; the default graph is oxl:DefaultGraph.
oxl:SystemGraphsystem graphA graph oxilite maintains itself: <oxilite:schema> (the registry) and <oxilite:vocabulary> (this vocabulary). Hidden with the schema graphs; never narrows reasoning or the shape index.
subclass of oxl:SchemaGraph
oxl:OntologyGraphontology graphAn RDFS / OWL ontology. Its axioms drive query-time reasoning over the graphs it applies to.
subclass of oxl:SchemaGraph
oxl:ShapesGraphSHACL shapes graphSHACL shapes for validating the graphs it applies to.
subclass of oxl:SchemaGraph
oxl:ShExGraphShEx schema graphA ShEx schema (in RDF) for validating the graphs it applies to.
subclass of oxl:SchemaGraph

Individuals

TermLabelMeaning
oxl:DefaultGraphdefault graphNames the default graph where an IRI is needed: as a registered schema graph, or as a target of oxl:appliesTo.

Example

PREFIX oxl: <https://oxilite.dev/ns#>

INSERT DATA { GRAPH <oxilite:schema> {
  <https://ex.org/onto/hr> a oxl:OntologyGraph ;
      oxl:appliesTo <https://ex.org/data/staff> ;
      oxl:version "2.1" .
  <https://ex.org/shapes/hr> a oxl:ShapesGraph .      # applies to every graph
} }

On oxilite, this write immediately scopes RDFS/OWL reasoning over <https://ex.org/data/staff> to the HR ontology and compiles the shapes; on any other store it is ordinary, queryable RDF. A graph without oxl:appliesTo applies to all graphs, and oxl:active false switches a registration off without removing it.
